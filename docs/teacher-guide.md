# 先生向けの使い方

先生のアカウントでログインすると「先生用の画面」が開きます（二段階認証が必要です）。
先生用の画面でできるのは、担当するクラス・生徒の管理と学習設定の指定です。アプリの機能そのものを変えたり、プログラムを動かしたりすることはできません。

## クラス

- 「クラスと生徒」→「新しいクラス」でクラスを作ります。作った先生が担当になります。
- 名前の変更・削除ができます（クラスを削除しても、生徒のアカウントと記録は消えません）。
- **共同担当**：「このクラスを担当する先生」で、ほかの先生の ID を入れて追加します。追加された先生は、そのクラスの生徒の記録を見たり管理したりできます。
  先生どうしが自動で全員の生徒を見られることはありません。追加した分だけ共有されます。

## 生徒のアカウント

### 発行

1. クラスを選び、「生徒のアカウントを発行」に ID・表示名・初期パスワードを入れます。
   - ID：英字で始まる英小文字と数字の4〜20文字（例：`sakura01`）。全角で入力しても半角にそろえます。
   - 表示名：ハンドルネーム。本名は使わないでください。
   - パスワード：8文字以上で英字と数字を含む。「自動で作る」を使うと、読み間違えにくい文字で作ります。生徒ごとに別のパスワードにしてください。
2. 「発行する」→ 表示された ID とパスワードを生徒に伝え、「閉じる」を押します。パスワードはこのあと表示できません。

### 管理（生徒の「くわしく・管理」）

- 練習の記録と成長グラフ（条件ごと。速さと正確率）
- 学習の初期設定：練習時間、難易度、ローマ字ガイド・キーボードガイド・指のガイド、音
  - 生徒が自分で設定を変えていなければ、この設定が使われます。「生徒の設定を初期設定に戻す」で、生徒が変えた設定を消せます。
- 表示名の変更
- **パスワードの再設定**：新しいパスワードを自動で作ります。現在のパスワードを先生が見ることはできません。再設定すると、その生徒のログイン中の端末もログアウトします。
- **停止**：ログインできなくなります（記録は残ります）。停止の解除もできます。
- **削除**：アカウントと練習の記録をすべて削除します。元に戻せません（確認のため ID を入力します）。
- 所属クラス：自分が担当するクラスに入れたり外したりできます。

## 追加教材

「追加教材」で、単語・読み・文章・テーマ・難易度を登録します。

- ローマ字入力の教材は、**読み（ひらがな）が必須**です。ローマ字で入力できない文字（漢字・カタカナ・英字など）が読みにあると登録できません。登録前に「ローマ字の例」が表示されます。
- 文章入力の教材は300文字まで。読みは任意（読みガイドに使います）。
- 「使えるクラス」にチェックしたクラスの生徒だけが使えます。「非公開」にすると生徒には表示されません。
- `<` `>` などのタグに使う記号は使えません。入力した内容は、画面ではすべて文字として表示します。
- 追加教材での練習は「参考ランク」です。

## 検定モードの問題（v1.1.0）

- 先生用の画面の「検定モードの問題（この端末）」、または「検定モード」→「先生の追加問題を管理する」で、画像・PDF のお手本と採点用の正解文で問題を作れます（手順は [exam.md](exam.md) の「5. 先生による問題の追加」）。
- 追加した問題は**その端末のブラウザにだけ**保存されます（クラウドには保存しません）。生徒の端末で使うには、「教材パックで書き出す」でファイルにして、生徒の端末の「検定モード → 先生の追加問題 → 教材パックを読み込む」で読み込みます。
- 正解文は「正解文を確認済み」にしてから自動採点に使います。PDF から取り出した文字は、読み順・タイトル・ページ番号などを必ず確認してください。
- 生徒の検定モードの記録は、生徒の「くわしく・管理」の「検定モードの記録」で見られます（タイピングのランクとは別です）。

## 記録の見方

- 生徒の一覧：練習回数、最終練習日、ローマ字・文章の最高速度（正式ランクの記録）、最新の正確率
- 生徒全員の公開ランキングはありません。

## 共有の端末での注意（生徒への声かけ）

- 終わったら「終了してログアウト」を押す
- ブラウザに「パスワードを保存しますか」と出たら「保存しない」
- 15分間操作がないと自動でログアウトします
