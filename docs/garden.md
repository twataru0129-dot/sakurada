# 桜ガーデン（v1.4.0）

ホームの「② ゲームモード」→ ゲームの選択 →「桜ガーデン」で遊びます。
短い文章をローマ字で打って水と花びらを集め、桜を育てて自分の庭を作るゲームです。時間制限・ゲームオーバーはありません。遊ばない日があっても桜は枯れず、水や花びらも減りません。

## 画面

- 上：桜ガーデンの名前、水・花びらの数、庭の切り替え（2つ目の庭が使えるようになってから）、遊び方、戻る
- 中ほど：庭（背景・桜・飾り）と、育成カード（えらんだ桜の名前・成長段階・水の量・水やり）
- 下：練習の欄（問題数をえらんで「練習を始める」）と、メニュー（庭づくり・桜を育てる・お店・図鑑・持ちもの）
- 練習中は、庭を表示したまま、練習の欄に文・読み（ひらがな）・ローマ字・何問目かを表示します。ゲームのメニューは出しません。
- PC・Surface（幅1000px以上・高さ600px以上。1368×912・1280×720 を確認）では、縦にスクロールしなくても全体が見えるように、庭の大きさを画面の高さに合わせます（縦横比のまま）。育成カードは庭の横に置き、庭を覆いません。
- スマートフォンでは上から順に並べ、練習中は庭を小さくして、文と画面のキーボードが見えるようにします。タッチ操作の端末では画面のキーボードを表示し、タップで入力できます（実物のキーボードでも入力できます）。

## 練習

- 問題：`src/data/garden/problems.json` の短い文章500文（自然・庭・桜の文章。表示文13〜20文字、読み15〜27文字）。カテゴリ・季節は、出題が偏らないようにするためだけに使い、選ぶ画面はありません。現実の日付で問題を絞りません。
- 1回の問題数は5・10・20問（既定10問。えらんだ問題数は記録に残ります）。
- 1回の練習の中で同じ問題は出しません。最近出た問題をできるだけ避け、同じカテゴリ・同じ主語・同じ文末の文が続かないように選びます（`src/core/garden/problems.ts`）。
- 判定は既存のローマ字判定（RomajiMatcher）に読みを渡すだけです。お手本は設定のローマ字の方式（ヘボン式／訓令式）で表示し、別の打ち方（shi / si、chi / ti、tsu / tu、nn など）もすべて正解です。
- 間違えたときは進まず、正しいキーを打てばそのまま続けられます。句読点・空白は読みに含まれないため入力しません。
- 「スペースでスタート」：開始待ちのときだけスペースで始まります。入力中のスペース・Enter・矢印などのキーは、ミスにも庭の操作にも使いません。Esc で「ひと休み」（続きを始める／練習を終える）。
- 日本語入力（IME）がオンのときは案内を出し、ミスには数えません。
- 次の問題に進むとき、前の問題の大きなメッセージは残しません。ごほうびは問題の欄の端に小さく表示し、終わったときにまとめて表示します。

## ごほうび（`src/core/garden/config.ts` の REWARD）

| | 水 | 花びら |
|---|---:|---:|
| 1問完成するごと | 1 | 1 |
| 完成した問題の読みのかなの文字数の累計 20文字ごと | 1 | — |

- かなの文字数は、問題が完成したときにその問題の読みの文字数で精算します。20文字未満の端数は次の問題・次の練習へ持ち越します。
- ローマ字の打鍵数は使いません（入力の方式の違いで得をすることはありません）。ミス・打ち直しは数えません。途中まで打った問題は精算しません。
- 問題ごとに記録するため、途中でやめても完成した問題のごほうびは残ります。もう一度開くと「続きから始める」で、残りの問題から始められます（同じ問題のごほうびは二重になりません）。
- 累計の完成問題数は、苗がお店に並ぶ条件と、庭が増える条件に使います。

## 桜の成長

苗木 → 若木 → つぼみ → 満開。水は共有で、育てる桜をえらんで使います。

| 桜 | 若木（累計の水） | つぼみ | 満開 |
|---|---:|---:|---:|
| 最初に無料で受け取るソメイヨシノ1本 | 5 | 10 | 20 |
| ほかの桜（2本目以降のソメイヨシノを含む） | 10 | 25 | 50 |

- 「水を1使う」「水を5使う」「満開まで水やり」。持っている水と満開までの残りの、小さい方までしか使いません。
- 満開の桜には水を使えません（「鑑賞する」になります）。いくつかの段階をまとめて越えたときは、最後の段階だけを知らせます。
- 最初の無料の特典は、その1本に記録します（あとで買ったソメイヨシノには使いません）。
- 庭に植えていない桜も、持ちもの・「桜を育てる」から育てられます。片付けても成長は残ります。

## お店

花びらで交換します（`src/data/garden/catalog.json`）。前の品種を買わなくても、条件の問題数に届けばお店に並びます。

| 桜の苗 | お店に並ぶ（累計の完成問題数） | 花びら |
|---|---:|---:|
| ソメイヨシノ | 0 | 最初の1本は無料、追加は20 |
| 八重紅枝垂 | 20 | 20 |
| 関山 | 50 | 30 |
| 旭山 | 90 | 35 |
| 鬱金 | 140 | 45 |
| 御衣黄 | 200 | 60 |
| 天の川 | 270 | 75 |
| 兼六園菊桜 | 350 | 100 |

| 庭の飾り | 花びら |
|---|---:|
| 花壇 | 10 |
| 飛び石（5つの石で1セット） | 10 |
| 木のベンチ | 30 |
| 石灯籠 | 40 |
| 小さな池 | 60 |

- 花びらが足りないときは、あと何枚必要かを表示します。交換の確認で二度押しても、1回だけ交換します。
- 売却・課金・広告はありません。

## 庭・持ちもの・図鑑

- 1つの庭に桜は3本まで（3つの植える場所）。植える場所に桜があるときは入れ替えます（元の桜は持ちものへ）。1本の桜を2つの庭に同時に植えることはできません（別の庭へ移せます）。
- 累計150問で2つ目、350問で3つ目の庭が使えます。庭の名前は変えられます（20文字まで）。
- 飾りは「庭づくり」で、地面のマス目に置きます。飾りをえらんで置く場所を押すか、置いた飾りをドラッグします。移動・片付け（持ちものに戻ります）もできます。桜の根元のまわりとほかの飾りには重ねられません（樹冠の下には置けます）。持っている数だけ置けます（持ちものに「庭に置いている数」と「持ちもの」の数を表示します）。
- 手前にあるものほど前に描きます（根元・飾りの下端の位置で決めます）。
- 図鑑：満開にした桜（8種類）を、名前・読み・花の色・木の形・説明と、木の画像の拡大で見られます。苗を手に入れた記録と、満開にした記録は別に残ります。
- 庭の画像の保存：背景と、その庭に置いた桜・飾りだけを描いた PNG（1586×992）を作ります（ボタン・練習の欄は入りません）。PC はダウンロード、iPhone・iPad では共有の画面から保存できます。

## 保存

- 記録は「出来事」（練習の開始・問題の完成・水やり・交換・植える・置く・名前の変更など）の一覧として保存し、画面の状態は出来事を古い順にたどって計算します（`src/core/garden/state.ts`）。
  - 出来事には ID があり、同じ ID は一度しか数えません。再送・再読み込み・別の端末からの同期でも、ごほうび・苗・飾りは二重になりません（問題の完成は「練習の ID ＋ 何問目か」が ID です）。
  - その時点で正しい出来事だけを反映します（花びらが足りない交換、必要以上の水やり、重なる配置などは反映しません）。2つの端末で同時に使った記録を合わせても、残高はマイナスになりません。
- ゲスト：この端末・ブラウザの localStorage（`sakura-type:guest-garden:v1`）。クラウドには送りません。「ゲストを終了」しても消えません（ほかのゲストの記録と同じ扱いです）。
- ログイン利用者：アカウント（Supabase の表 `garden_events`。本人だけが追加・閲覧、変更・削除不可）。別の端末でログインしても同じ庭です。送れなかった変更は「アカウントに保存できていない変更があります。」と表示し、もう一度送れます。端末には残しません。表がまだないときは、保存できたように見せず、案内を表示します。導入は [setup.md](setup.md) の手順2（7）。

## 画像

- 提供された素材（背景1枚、桜の成長4段階、飾り5種類）を使います。元の PNG は `assets/garden-source/` に残し（配信には含めません）、`scripts/garden_assets.py` で WebP に切り出したものを `src/assets/garden/` に置いています。描き直しはしていません。
- 成長4段階をまとめた素材シート（左上=苗木、右上=若木、左下=つぼみ、右下=満開）は、等分割の線を越えて描かれている枝・樹冠があるため、透明でない部分のつながりごとにどの段階のものかを決めて切り出しています（隣の段階が混ざらず、枝先が切れません）。
- 木の根元（接地点）は、木の下の草地の中ほどとし、植える場所に根元を合わせて描きます。大きさは画像の余白ではなく、品種（旭山は小さめ）× 段階 × 奥行きで決めます（`src/core/garden/layout.ts`）。
- 画像は、桜の特徴を参考にしたゲーム用のイラストです（実際の桜の写真ではありません）。画面の文字・数字・ボタン・進み具合は、画像ではなくアプリで表示しています。

## 調整するとき

- 価格・お店に並ぶ条件・画面の文章：`src/data/garden/catalog.json`
- 成長に必要な水・ごほうび・庭の数と条件・問題数：`src/core/garden/config.ts`
- 植える場所・マス目・飾りの大きさ：`src/core/garden/layout.ts`
- 画像を作り直す：`python3 scripts/garden_assets.py`（Pillow・numpy・scipy が必要）
