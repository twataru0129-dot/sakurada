# 検定モード（v1.1.0）

お手本の文章を見ながら、白紙の A4 用紙（入力欄）に日本語の文章を入力するモードです。
日本語入力（IME）で漢字に変換しながら入力します。扱うのは**文章の入力・改行・段落だけ**です（図・表・地図の作成、文字の装飾、中央揃えなどの文書編集は行いません）。

> 日本語ワープロ検定の速度分野を参考にした、**桜打独自の練習**です。採点は下に書いた練習用の独自の規則で、公式の検定の採点を再現したものではありません。**公式検定の合格を認定するものではありません。**

---

## 1. 収録問題（30問）

`src/data/exam/exam_problems.json` のオリジナル文章を、省略・要約・差し替えをせずにそのまま使います（入力の対象は `answerText`。タイトルや文字数は入力しません）。
本文は各段階の目安文字数より長くしてあり、時間内に先頭からどこまで正確に入力できるかを測ります。最後まで入力できなくても、それだけでミスにはなりません。

| 段階 | 問題数 | 標準時間 | 目安文字数 | 1ミスの減点 |
|---|---|---|---|---|
| 4級相当 | 5 | 10分 | 200文字 | 1文字 |
| 3級相当 | 5 | 10分 | 300文字 | 1文字 |
| 準2級相当 | 5 | 10分 | 400文字 | 3文字 |
| 2級相当 | 5 | 10分 | 500文字 | 3文字 |
| 準1級相当 | 5 | 10分 | 600文字 | 5文字 |
| 1級相当 | 5 | 10分 | 700文字 | 5文字 |

（練習用の段階設定です。`src/core/exam.ts` の `GRADES` と、データベースの `exam_results` の制約で同じ値を使っています）

時間は標準の **10分** のほか、短い練習として **3分・5分・時間制限なし** を選べます。3分・5分・時間制限なしでは、10分基準の「目安達成」の判定は行いません。

## 2. 練習のしかた（生徒）

1. ホーム →「③ 検定モード」→「収録問題」または「先生の追加問題」を選ぶ。
2. 段階を選び、問題名を選ぶ（問題名・段階・制限時間・自動採点の有無が表示されます）。時間を選んで「はじめる」。
3. 練習画面：左がお手本、右が白紙の A4 用紙、上に残り時間・確定済みの入力文字数・「終了する」。左右はそれぞれスクロールできます。「A−／A＋」で文字の大きさを変えられます。
   - お手本の画面上の行の折り返しは、入力しなくてかまいません。改行（Enter）が必要なのは、段落の終わり（↵ の印）だけです。
   - 画像・PDF のお手本は、拡大・縮小・回転・ページ移動ができます。拡大したときは、スクロール（マウスではドラッグ）で本文を動かせます。
4. スペースキーかスタートボタンで開始します。開始のスペースは本文に入りません。開始後は入力欄にカーソルが移ります。
   入力中のスペース・Enter は変換・改行にそのまま使えます（アプリの操作には使いません）。
5. 入力中は誤りを表示しません。時間になるか「終了する」で、答え合わせの画面になります。

日本語入力について：変換中（未確定・下線がある状態）の文字は、文字数にも採点にも含めません。時間になった瞬間の**確定済みの文章**で締め切り、そのあとで IME が確定した文字は結果に加えません。
OS やキーボードの予測変換は、アプリから完全には止められません（入力欄では、ブラウザのスペルチェック・自動修正を切っています）。貼り付けはできません。

時間は開始時刻からの経過で測るため、別のタブに切り替えている間も進みます。

## 3. 採点の規則（版：exam-v1）

### 比べる文字

- 最終的に残っている、確定済みの入力本文を採点します。途中で打ち間違えて直した文字は、ミスに含めません。
- 改行・半角スペース・全角スペース・タブは、文字数にも比較にも含めません。句読点・数字・その他の記号は比べます。
- Unicode は NFC にそろえます。全角と半角（例：「１」と「1」）、異なる記号（例：「、」と「，」）は、別の文字として扱います。

### 誤りの判定（対応付け）

同じ位置の文字を比べるだけの方法は使いません。置換・挿入・脱落を考えた対応付け（編集距離のアラインメント）で比べるため、1文字抜けても、その後ろが全部誤りにはなりません。

- **先頭を固定**します。入力本文は、お手本の先頭から入力したものとして比べます。入力本文を、お手本の途中の都合のよい場所に当てはめることはしません。
- 入力本文は**すべて**比べます。誤って入力した末尾を切り捨てることはしません。
- お手本の末尾の、**まだ入力していない部分**はミスに数えません。途中の脱落はミスです。
- 費用：一致 0、置換 1、挿入（余分な文字）1、脱落（抜けた文字）1。
- 同じ費用の候補があるときの優先順位：
  1. 費用（置換＋挿入＋脱落）が最も小さい
  2. 一致した文字数が最も多い
  3. お手本をより先まで使ったもの（例：お手本「あいうえ」に入力「あいx」→「う を x と入力した（置換1）」とし、「x が余分で、う から先は未入力」とはしません）
  4. 途中の各位置では、斜め（一致・置換）→ 脱落 → 挿入 の順に選びます（例：お手本「あいう」に入力「あう」→「い の脱落」）
- 実装：`src/core/examScoring.ts`。正解文は 5,000 文字まで、入力は 8,000 文字までを比べます。

### 成績

- ミス数 ＝ 置換 ＋ 挿入 ＋ 途中の脱落
- 得点文字数 ＝ 入力文字数 − ミス数 × 段階の減点（0 未満は 0）
- **目安達成**：標準の10分を最後まで計測し、得点文字数が段階の目安文字数以上のとき。「公式検定合格」とは表示しません。
- 短縮練習（3分・5分）・時間制限なし・途中終了では、10分基準の判定を出しません。
- お手本の最後まで入力して早く終えたときは「全文入力完了」と表示し、10分間を計測した結果とは区別します。

結果画面には、入力文字数・一致した文字数・ミス数（置換・余分・抜けの内訳）・得点文字数（計算式）・経過時間と、お手本と入力本文の違いを表示します。
違いは色だけでなく、記号でも示します：置換「入力→正」（波線）、余分「＋」と取り消し線、抜け「［抜:文字］」、未入力「（未入力）」。凡例も表示します。

## 4. 記録

- 検定モードの記録は、タイピングの記録とは**別に**保存します。タイピングのランクの計算には使いません。
- 記録する内容：実施日時、問題 ID・問題名・**問題の改訂番号**・段階、時間の設定と実際の経過時間、終了理由、自動採点の有無、入力文字数、一致した文字数、ミス数、得点文字数、目安達成の有無、採点規則の版。
- 入力した文章・正解文・お手本は記録に保存しません（結果画面でその場だけ表示します）。
- あとで問題を編集しても、過去の成績を今の本文で採点し直しません。
- 保存先：ゲストはこの端末・ブラウザ（localStorage のキー `sakura-type:guest-exam-history`、最新100回分）。ログイン利用者はアカウント（Supabase の `exam_results`）。ゲストとアカウントの記録は混ぜません。通信に失敗しても、ゲストの保存場所には切り替えません。
- 「練習の記録」画面の「検定モードの記録」で見られます。先生は、生徒の「くわしく・管理」で担当生徒の記録を見られます。
- 先生の「生徒用プレビュー」の結果は記録しません。

## 5. 先生による問題の追加（画像・PDF）

「検定モード」→「先生の追加問題を管理する」（先生用の画面の「検定モードの問題（この端末）」からも開けます）。

> **だれが管理できるか**：ログイン機能（Supabase）を設定していないときは、この端末を使う人が管理できます。設定しているときは、先生のアカウントでログインしたときだけ管理の画面を表示します。
> これは**画面の表示を分けているだけ**で、クラウド上の権限の制御ではありません。端末内（ブラウザ）の教材は、その端末を操作できる人なら技術的には変更できます。生徒の端末で問題を変えられないようにする仕組みが必要な場合は、将来のクラウド共有（サーバー側で権限を確認する方式）で対応します。

### 追加の手順

1. 「＋ 問題を追加する」→ **問題名**を入力します（60文字まで）。
2. **級相当の段階**と**制限時間**（10分（標準）・5分・3分・時間制限なし）を選びます。
3. **お手本**を選びます：PNG・JPEG・WebP の画像（スマートフォンで撮影したプリントの写真も可。複数枚可）または PDF（1つ）。
   - PDF：使うページに印を付け、↑↓で順番を、「↻ 回転」で向きを決めます。
   - 画像：↑↓で順番、「↻ 回転」で向き、「外す」で取り除きます。
4. **プレビュー**で、お手本の見え方を確かめます（拡大・回転・ページ移動ができます）。
5. **採点用の正解文**を登録するか、「採点なし」を選びます。
   - 正解文は、お手本の画像・PDF とは**別に**保存します。直接入力・貼り付け・修正ができます。段落の終わりは改行してください（採点では改行・空白は比べません）。
   - 文字情報のある PDF では「PDF から文字を取り出す（補助）」が使えます。取り出した文章は、**読み順・タイトル・ページ番号・余分な空白などを必ずお手本と見比べて確認・修正**してください。
   - 画像やスキャンした PDF の文字は、自動では読み取りません（OCR はこの版にはありません）。お手本を見ながら入力するか、貼り付けてください。教材を外部のサービスへ送ることはしません。
   - 「**正解文を確認済み**」に印を付けるまで、自動採点の問題としては保存できません。正解文を書き換えると、確認済みの印は外れます。
   - 正解文の文字数（改行・空白を除く）が表示されます。段階の目安文字数より短いときは通知しますが、短い教材として保存できます。
6. 「生徒向けに表示する」を確かめて「この端末に保存する」。一覧の「**生徒用プレビュー**」で、生徒の画面で練習してみてください（プレビューの結果は記録しません）。

### 管理

一覧で、編集（保存すると改訂番号が1つ上がります）・複製・削除・生徒向けの表示／非表示・生徒用プレビューができます。

### 採点なしの問題

結果画面には、入力文字数・経過時間・入力した文章だけを表示し、ミス数や目安達成は出しません。生徒には、開始前に「採点なし」と表示します。

### 容量の上限と、うまくいかないとき

上限は `src/core/examFiles.ts` の定数で変えられます：1ファイル 20MB（`MAX_FILE_BYTES`）、PDF 20ページ（`MAX_PDF_PAGES`）、画像 20枚（`MAX_IMAGE_FILES`）、この端末の問題 300問（`MAX_TEACHER_PROBLEMS`）。

| 表示 | 対処 |
|---|---|
| HEIC / HEIF 形式のため使えません | iPhone・iPad の写真の形式です。JPEG か PNG に変換して選んでください（「互換性優先」で撮影する、写真を JPEG で書き出す など） |
| 対応していない形式です | PNG・JPEG・WebP・PDF に変換してから選んでください（GIF・BMP・TIFF・Word などは使えません） |
| パスワードで保護された PDF は使えません | パスワードを解除した PDF を作ってから選んでください |
| PDF が壊れている | 元のファイルから PDF を作り直してください |
| ○ページあります（20ページまで） | 必要なページだけの PDF に分けてください |
| 容量が大きすぎます | 画像を小さくする、PDF を分ける |
| 保存できる容量が足りません | 使わない問題を削除する、ファイルを小さくする |
| この端末に保存できません | プライベートブラウズになっていないか、サイトのデータを保存しない設定になっていないかを確認してください |

PDF は、表示するページだけを1ページずつ描画します（全ページを一度に高解像度の画像にはしません）。PDF の中のスクリプトは実行しません。

## 6. 保存と配布（「この端末に保存」と「教材パックで配布」）

- **この端末に保存**：追加した問題は、その端末のそのブラウザ（IndexedDB）に、画像・PDF のファイル本体ごと保存されます。再読み込みしても使えます。**ほかの端末・ほかのブラウザには自動では届きません。** ブラウザのデータを削除すると消えます。
- **教材パックで配布**：一覧で問題に印を付け「教材パックで書き出す」→ `sakura-exam-pack-年月日.sakuraexam` というファイルができます。問題の設定・採点用の正解文・お手本のファイルを1つにまとめたものです。**生徒の成績・入力した文章・ログイン情報・認証情報は入りません。**
- 生徒の端末で読み込む：「検定モード」→「先生の追加問題」→「教材パックを読み込む」でファイルを選び、確認の画面で「この端末に追加する」。
  - 形式・版・容量・ファイルの参照・中身の照合値（SHA-256）・ID の重複を確かめます。壊れている・形式が違うファイルは読み込みません。
  - この端末に**同じ ID の問題があるときは上書きしません**。内容が同じなら「読み込み済み」として追加せず、内容が違うときは「別の問題として追加する」を選んだときだけ、新しい ID で追加します。
- 教材パックの配り方の例：学校の共有フォルダー、校内の Teams・Google Classroom などのファイル配布、USB メモリ。

保存処理は `src/data/examStore.ts` の `ExamProblemStore` にまとめてあり、将来クラウド保存を追加するときは同じ形の実装を追加します（そのときは、データベースとファイル保存先の権限をサーバー側で、既存の先生・クラスの規則に合わせて制御します）。この版では、追加問題のクラウド共有は行いません。

## 7. Supabase を使っている場合の追加の設定

ログイン利用者の検定モードの記録を保存するには、データベースに `supabase/migrations/20261008000000_exam_results.sql` を適用します（[setup.md](setup.md) の手順2）。

- 本人だけが追加・閲覧でき、先生は担当の生徒の記録だけを閲覧できます（二段階認証済みのとき）。変更・削除はできません。
- 得点文字数と目安達成は、データベース側でも同じ規則で計算し直します。ミス数・一致した文字数は、正解文がデータベースにないためアプリが計算した値を受け取り、値の範囲・組み合わせ（段階と減点、時間切れと経過時間、採点ありなしの項目など）を検証します。
- 適用する前は、ログイン利用者の検定モードの記録は保存に失敗し、「保存できませんでした」と表示されます（ゲストの保存場所には切り替えません）。
