# 文書作成モード（v2.0.0）

ホームの「③ 文書作成モード」は、**見本の文章を見ながら、段落ごとに日本語を入力し、改行・見直し・修正をして一つの文書を完成させる**練習です。
完成した文書は、その場で**印刷**したり、**Word のファイル（.docx）で保存**したりできます。

- 速さや得点を競う練習ではありません。日本語入力（IME）で自分で漢字に変換し、改行し、見直して直す練習です。
- 文字の装飾・中央揃え・図・表・地図の作成は行いません。
- v1.9.0 までの「検定モード」（10分・級別の減点・目安達成）は、このモードに置き換わりました。旧検定モードの記録は消さずに「旧検定モードの記録」として残します（「8. 記録」）。
- 画面の URL（`#/exam` など）・先生の追加問題の保存先・教材パックの拡張子（.sakuraexam）は、これまでと同じです。

## 1. 問題（収録30問・やさしい順）

- 収録問題は、これまでの `src/data/exam/exam_problems.json` の30問です。**本文・タイトル・ID は変えていません。**
- 問題の選択の画面では、**タイトル・本文の文字数（改行を除く）・段落数**を表示します。級・制限時間は表示しません。
- 並び順は**やさしい順**です。元の段階（4級相当 → 3級相当 → 準2級相当 → 2級相当 → 準1級相当 → 1級相当）の順に並べ、同じ段階の中は、本文の長さと漢字の多さ（文字数 ×（1＋漢字の割合））の小さい順にしました。
  並び順は `src/data/exam/document_order.json` に**明示的に**書いてあります（30問をちょうど1回ずつ。自動テストで確かめます）。
- 先生の追加問題は「先生の追加問題」のタブに、先生が決めた並び順（小さい順）→ 作成した順に並びます。

## 2. 練習のしかた（生徒）

1. 問題を選んで「はじめる」→ 説明を読んで「スタート」。**スタートを押したときから時間を測ります。**
2. 画面の中央に A4 の紙のような用紙があり、段落ごとに **「段落の番号 → 見本の文章 → その下に自分の入力欄」** が縦に並びます（左右には分けません）。
3. 見本を見ながら入力欄に入力します。日本語入力（IME）をオンにして、自分で漢字に変換します。
4. 見本の段落の終わりの **「↵ 改行」** で **Enter** を押すと、改行したことを記録して、次の段落の入力欄へ移ります。
   画面の幅で折り返されたところは、改行しなくてかまいません（折り返しは誤りにしません）。
5. 上の **「チェック」** を押すと、見本と違うところに赤い波線と小さな印が付きます。直したら、もう一度「チェック」できます。
6. **「全文を確認」** で、自分が入力した文章を一つの文書として見られます（見本は入れません。時間は止まりません）。
7. **「完成！」** を押すと完成です。間違いが残っていても完成できます。

画面の上の帯には、題名・経過時間・入力した文字数・文字の大きさ（A−／A＋）・「チェック」「全文を確認」「完成！」「途中でやめる」があります。
Surface・タブレット・スマートフォンの幅でも、横にはみ出さないようにしています。

### キーの動き

入力欄はブラウザの普通の入力欄（textarea）です。**スペース・Enter・Backspace・Delete・矢印キー・範囲選択・元に戻す（Ctrl＋Z）はブラウザのまま**動きます。入力中に文字を消したり、正しい文字に置き換えたりはしません。間違っていても先へ進めます。

| 操作 | 動き |
| --- | --- |
| 段落の終わりで Enter（変換中ではない） | 改行を記録して、次の段落の入力欄へ移ります（最後の段落では移りません） |
| 変換を確定する Enter | 確定だけ。改行も移動もしません（確定の直後の Enter も二重に扱いません） |
| 文の途中で Enter | その位置に改行が入ります（次の段落へは移りません） |
| 空の段落で Enter | 先へ進まず、「入力してから Enter を押しましょう」と案内します |
| Enter の押しっぱなし | 繰り返しでは先へ進みません（空の段落を飛ばして進みません） |
| 段落の先頭で Backspace | 前の段落の終わりの改行（記録したもの）を消して、前の段落の終わりへ戻ります。文字は消しません |
| 段落の終わりで Delete | 記録した改行を消します |
| 段落の先頭で ↑・← ／ 終わりで ↓・→ | 前の段落・次の段落へ移ります |
| 貼り付け・ドラッグでの入力 | 生徒の入力欄ではできません（先生の問題の登録欄ではできます） |

- 最後の段落の終わりの改行は、あってもなくてもかまいません。
- 文書を作るときに、生徒が押していない改行を**自動では補いません**。改行の違いはチェックで知らせますが、完成のじゃまはしません。

## 3. チェックの規則（版：doc-v1）

チェックは **「チェック」を押したときだけ**行います（入力中は誤りを知らせません）。完成のときにも同じ規則で最後まで確かめ、記録に残します。

### 何と何を比べるか

- 見本の段落と、その段落の入力欄の文章（＋記録した段落の終わりの改行）を比べます。
- **確定していない文字（変換中）・まだ入力していない段落・いま入力している段落の、まだ入力していない残り**は誤りにしません。
- 段落の終わりで改行した段落・あとの段落に入力がある段落は「終えた段落」として、**最後まで**比べます（終わりの抜けも示します）。完成のときは、すべての段落を最後まで比べます。

### 誤りの種類

| 種類 | 表示 |
| --- | --- |
| 違う文字・余分な文字 | 赤い波線（どの字と違うかを下に書きます） |
| 抜けた文字 | 小さな「∧」の印（続けて抜けた文字は1つの印にまとめます） |
| 空白の違い（余分・足りない・全角と半角の違い） | 黄色の波線、または「␣」の印 |
| 改行の違い（段落の終わりで改行していない・途中の余分な改行） | 紫の「↵」の印 |

- 印は表示だけで、**本人の文章には入れません**。
- 文字の比べ方は、空白・改行を除いた文字の列を、置換・挿入・脱落を考えた対応付け（アラインメント）で比べます。**1文字抜けても、その後ろがすべて誤りになることはありません。**
- **文字の誤り**と、**空白・改行の誤り**は、別々に数えます。画面の幅による折り返しは誤りにしません。
- 段落の文章を直すと、その段落のチェックの表示を外します（「もう一度チェックを押すと確かめられます」と表示）。自動ではチェックし直しません。
- 変換中に「チェック」を押すと、確定してから押すように案内します。

赤い波線は、入力欄と同じ位置・同じ折り返しで重ねた「写し」に描いています。入力欄そのものは変えないので、IME の変換・カーソル・範囲選択は普段どおりです。

## 4. 時間と完成

- 時間は「スタート」から「完成！」で確定するまでです。別のタブに移っている間・「全文を確認」の間も進みます。制限時間はありません。
- **完成できる条件**：すべての段落に、空白・改行だけではない入力があること。誤字・脱字・空白や改行の違いがあっても完成できます。
- 空の段落があるときは「段落 ○ がまだ空です」と知らせ、その段落の入力欄へ移ります。
- 変換中の文字があるときは、確定してから押すように案内します（確定していない文字は捨てません）。
- 「完成！」→「完成する」を続けて押しても、記録は1回だけです。
- 「途中でやめる」を選ぶと、その時点の入力で「途中で終了」として記録します。

## 5. 完成画面・印刷・Word

- 「文書が完成しました」と完成までの時間を表示し、その下に**本人が入力した文書**（タイトル＋全文）を A4 の紙のように表示します。赤い波線は付けません。誤字も本人の入力のまま表示します（正しい字に置き換えません）。
- **「見本と比べて確認する」**で、段落ごとの見本と、印の付いた自分の入力・誤りの数を、別の表示に切り替えて見られます。
- **「印刷する」**：A4 縦で、**タイトルと本人の全文だけ**を印刷します（ボタン・見本・時間・印・画面の上の帯は印刷しません）。長い文書は複数ページに分かれ、行の途中で切れません。
- **「Wordで保存する」**：本物の Word のファイル（.docx）を**この端末の中で作って**ダウンロードします（本文を外部へ送りません）。
  - 用紙 A4 縦・余白 25mm・書体 游明朝（日本語）・10.5pt・行間 1.5行。1行目にタイトル、そのあとに本人の文章。
  - 本人が入力した改行は段落、空白（半角・全角・連続）はそのまま、タブは Word のタブ。誤字も入力のままです。
  - ファイル名は「タイトル.docx」（ファイル名に使えない `\ / : * ? " < > |` などは置き換えます）。
  - 游明朝がない端末では、Word などが近い書体に置き換えて表示します。

## 6. 先生による問題の追加

「文書作成モード」→「先生の追加問題を管理する」（先生用の画面の「文書作成モードの問題（この端末）」からも開けます）。

### 追加の手順

1. 「＋ 問題を追加する（タイトル＋見本の文章）」。
2. **タイトル**を入力します。
3. **見本の文章**を入力するか、**貼り付け**ます（この欄は貼り付けできます）。改行したところが段落の区切りになります。
4. 下の **段落のプレビュー** で、生徒の画面での段落の区切りを確かめます。
   - 空の行があると知らせます。**勝手には消しません。**「空の行を取り除く」を押したときだけ取り除きます（段落の中の改行・空白は変えません）。
   - 長すぎる文章（5000文字まで）も知らせます。
5. 「段落の区切りを確認しました」にチェックします（見本の文章を変えると、チェックは外れます）。
6. 並び順（小さいほど先。0〜9999）と「生徒に表示する」を決めて、保存します。

級・制限時間の設定はありません。

### 管理

一覧では、並び順・タイトル・見本の文章の状態・種類・生徒向けの表示・改訂番号を見られます。

- **生徒用プレビュー**：生徒と同じ画面で試せます（記録は保存しません）。
- **編集**：保存すると改訂番号が1つ上がります。過去の記録には、そのとき使った改訂番号が残ります。
- **複製**・**削除**・**生徒向けの表示／非表示**。

### 旧検定モードの画像・PDF の問題

v1.9.0 までに追加した画像・PDF の問題は、**原本のファイル・問題の ID・改訂番号をそのまま残します**。

- 見本の文章（旧「正解文」）が登録・確認済みなら、そのまま文書作成モードで使えます。
- 見本の文章がない・確認していない問題は、一覧に **「見本の文章を登録・確認すると使用できます」** と表示し、生徒の一覧には出しません。
- 編集の画面で原本を見ながら（文字情報のある PDF は「PDF から文字を取り出す（補助）」も使えます）、見本の文章を入力して確認すると使えるようになります。

## 7. 保存と配布（「この端末に保存」と「教材パックで配布」）

- 追加した問題は、**この端末のこのブラウザ（IndexedDB）にだけ**保存します。クラウドには送りません。ほかの端末には自動で届きません。
- ほかの端末で使うときは、問題に印を付けて「教材パックで書き出す」→ 生徒の端末の「文書作成モード → 先生の追加問題 → 教材パックを読み込む」。
- 教材パック（.sakuraexam）には、問題のタイトル・見本の文章・並び順（旧検定の問題は原本のファイルも）を入れます。成績・入力した本文・ログイン情報は入れません。
- 教材パックの形式は **版 2**（v2.0.0）です。見本の文章だけの問題（ファイルなし）と並び順を入れられるようにしました。**v1.x で書き出した版 1 の教材パックも、そのまま読み込めます。**
- 読み込むとき、同じ ID の問題がこの端末にあれば上書きしません（同じ内容なら「読み込み済み」、違う内容なら「別の問題として追加」を選べます）。

## 8. 記録

- 文書作成モードの記録は、タイピング・ゲーム・旧検定モードの記録とは**別に**保存し、ランクの計算には使いません。
- 記録に残すもの：日時、問題の ID・タイトル・改訂番号、完成（または途中で終了）、所要時間、入力文字数（改行を除く）、段落数、最終確認での文字の誤り（違う・余分・抜け）、空白の誤り・改行の誤り、規則の版（doc-v1）。
- **入力した本文は記録に入れません**（クラウドにも送りません）。印刷・Word の保存は、完成画面を開いているときにその場で行ってください。
- ゲスト：この端末・ブラウザに最新100回分（`sakura-type:guest-document-history`）。「練習の記録」→「文書作成の記録」で見られ、削除できます。
- ログイン：アカウントの記録（クラウドの表 `document_results`）。担当の先生は、生徒の「くわしく・管理」で見られます。
- **旧検定モードの記録**（v1.9.0 まで）は、「文書作成の記録」の下の「旧検定モードの記録」に、当時の成績のまま表示します（文書作成モードの記録に読み替えたり、計算し直したりしません）。
- Supabase を使っていない場合も、ゲストとして使えます。

## 9. Supabase を使っている場合の追加の設定

ログイン機能を使っている場合は、`supabase/migrations/20261014000000_document_results.sql` を追加で実行してください（[setup.md](setup.md)）。
実行する前でも、文書作成モードの練習・印刷・Word の保存はできます。ログイン利用者の記録だけが保存できず、完成画面に「記録は未保存です：クラウドの記録の表がまだありません」と表示します。

## 付録：旧検定モード（v1.9.0 まで）の採点の規則（版：exam-v1）

「旧検定モードの記録」に表示している数値は、次の規則で当時計算したものです。v2.0.0 では、この規則で新しく採点することはありません（記録の読み替え・計算し直しもしません）。

- 確定済みの入力本文を、改行・空白を除いて、先頭を固定した対応付け（置換・挿入・脱落。費用は各1）で正解文と比べ、お手本の末尾のまだ入力していない部分はミスに数えませんでした。
- ミス数 ＝ 置換 ＋ 挿入 ＋ 途中の脱落、得点文字数 ＝ 入力文字数 − ミス数 × 段階の減点（0 未満は 0）。
- 目安達成：標準の10分を最後まで計測し、得点文字数が段階の目安文字数以上のとき（公式検定の合格ではありません）。
- 記録は `exam_results`（ログイン）・`sakura-type:guest-exam-history`（ゲスト）に保存していました。どちらも v2.0.0 でそのまま残しています。
- 対応付けの実装（`src/core/examScoring.ts` の `alignExam`）は、文書作成モードのチェックでも使っています（段落を終えたときは、見本の最後まで比べる指定を加えて使います）。
