# 採点・ランク・出題のきまり

## 速さと正確率

| | ローマ字入力 | 文章入力〈変換あり〉 |
|---|---|---|
| 正しい数 | 正しく打ったキーの数（打鍵数） | 正しく受理した日本語の文字数（改行は数えない） |
| ミス | 間違ったキーを押した回数 | 誤って確定した文字数（累積。修正しても残る） |
| 速さ | 正しい打鍵数 ÷ 練習した分 ＝ **打／分** | 正しい文字数 ÷ 練習した分 ＝ **字／分** |
| 正確率 | 正しい打鍵 ÷（正しい打鍵＋ミス打鍵）×100 | 正しい文字 ÷（正しい文字＋累積の誤確定文字）×100 |

- 練習した時間は、問題を読む時間・直す時間も含めた時間全体です。完走のときは選んだ時間（3・5・10分）、途中終了のときは終えるまでの時間です。
- 入力がまったくないときは、正確率は「—」、ランクは「未判定」です。
- 画面の数字は小数第1位で**切り捨て**て表示します。ランクの判定には、丸める前の値を使います（整数の掛け算で比べるため、表示の丸め方に左右されません）。
- ランクと速さ・正確率は、保存するときにデータベース側でも同じ計算をし直します（`private.judge_rank`）。アプリとデータベースの判定が一致することはテストで確かめています。

## 文章入力のミスの数え方

- 判定するのは、IME で**確定した文字だけ**です。変換中（下線がついている）の文字は判定しません。
- 確定するたびに、前回判定した内容との差から「今回新しく確定した文字」を求めます。見本との最適な対応付け（編集距離）で誤りになった文字のうち、今回の範囲にあるものだけをミスに加えます。
  - 誤変換は文字数分（例：「機関」を「期間」→ 2）
  - 余分な文字（挿入）は1文字ずつ、抜けた文字（脱字）は後ろの文字を確定したときに1文字ずつ
  - 正しい途中入力は、後半が未入力でもミスにしません
  - 同じ誤りを残したまま続けて入力しても、重複して数えません
  - 削除（Backspace など）はミスにしません。修正したあとで新たに誤って確定したら、新しいミスです
- 全角・半角の英数字と記号（例：「３」と「3」、「（」と「(」）は同じ文字として扱います。それ以外（「、」と「，」など）は区別します。
- 見本どおりに完成するまで、次の問題へは進みません。完成すると自動で次の問題へ進みます。
- Enter キー：変換の確定に使った Enter は何もしません。見本で改行がある位置だけ改行を入力できます。改行がない位置の Enter は入力されず、ミスにもなりません（問題のスキップや二重判定を防ぐため）。
- 貼り付け（コピー＆ペースト）はできません。
- 時間切れのとき、変換中の文字は数えません。確定済みで正しい途中入力は数えます。

## 終わりかた（v1.0.2）

- **時間で練習**：3分・5分・10分。残り時間を表示し、時間いっぱいで終わります。
- **問題数で練習**：25問・50問。時間の制限はなく、経過時間を表示します。正しく入力し終えた問題を1問として数え、ミスをしても数は減りません。決めた数を完成したら、次の問題を出す前に終わります。速さは「正しい数 ÷ 実際にかかった時間」です。
- どちらも、スペースキーかスタートボタンを押した瞬間から時間を測ります（待っている間は含みません。開始に使ったスペースは入力にもミスにも数えません）。
- 時間制（3・5・10分）と問題数制（25問・50問）は、それぞれ別の条件として記録し、自己ベストや前回比較を混ぜません。
- v1.0.1 までの記録は、すべて「時間で練習」の記録として扱います。

## ミスした問題の詳細（ローマ字入力・v1.0.2）

- 練習中、ミスを判定したその時に、出題回（何問目か）・問題・読み・かなの単位・入力位置・その時点のガイドの文字・入力済みの文字列・正しいと判定されるキー・実際に押したキーを記録します。あとから推測はしません。
- 結果画面には、ミスがあった出題回だけを表示します（ミスがなければ欄そのものを表示しません）。同じ問題が何回出ても、出題回ごとに分けます。時間切れ・途中終了で入力途中だった問題は「入力途中」と表示します。
- 問題ごとの正確率 ＝ その出題回の正しい打鍵数 ÷（正しい打鍵数＋ミス数）×100。かかった時間は、その問題が出てから完成（または練習の終わり）までで、開始待ちの時間は含みません。
- shi と si のように、別の正しい打ち方はミスにしません。説明には、その時ガイドに出ていた文字と、ほかに正しかったキーを分けて表示します。
- この詳細はその場の結果画面で見るためのもので、クラウドには保存しません（文章入力は対象外）。

## 練習の記録と成長グラフ（v1.0.3）

- 練習を終えるたびに自動で記録します（開始待ちの画面を離れただけでは記録しません）。記録 ID で二重の保存を防ぎます。
- 保存先：ゲストはこの端末・ブラウザ（最新100回、全条件の合計。101回目からは古い記録から入れ替え）、ログイン利用者はアカウント（クラウド。画面には新しい順に100件を表示）。
- 保存時のランク・速さ・正確率・ランク基準の版をそのまま残し、あとから現在の基準で書き換えません。
- 成長グラフ・平均・自己ベストは、選んだ同じ条件（conditionKey：種類・終わりかた（3/5/10分・25/50問）・入力方法・問題の種類・テーマ・難易度・問題セットの版）の**完了した記録**だけで計算します。途中終了は一覧に残しますが、計算には入れません。ヘボン式・訓令式の違いでは条件を分けません。
- 速さのグラフの縦軸は 0 から、正確率は 0〜100％。実際の記録（実線・●）と直近5回の平均（点線）を示します。5回たまるまで平均は作りません。
- 「最初の5回と最近の5回」の比較は、完了した記録が10回以上あるときだけ、重ならない最初の5回と最近の5回の平均で比べます。速さと正確率の両方の変化を、事実どおりに伝えます。
- 自己ベストや「最初の5回」は、全期間ではなく、保存・取得した直近100回の記録の中での値です。

## 正式ランクと参考ランク

- **正式ランク**：「時間で練習」で「標準問題」を、時間いっぱいまで練習したとき（完走）。
- **参考ランク**：問題数で練習（25問・50問を完了しても参考ランク）、途中終了、一般問題で難易度を選んだ練習、🌸桜モード、先生の追加教材。参考ランクと自己ベストも表示しますが、正式ランクとは別に記録します。

### 標準問題の出題ルール

一般問題（身近な生活、食べ物・動物・自然、趣味・音楽・スポーツ、買い物・公共施設、情報・パソコン、短い説明文）から、次の難易度の順番をくり返して出します。

- ローマ字入力：**1 → 1 → 2 → 2 → 3**（やさしい単語2問 → 小さい文字・「ん」などを含む単語2問 → 短文1問）
- 文章入力：**1 → 2 → 1 → 2 → 3**（初級 → 中級 → 初級 → 中級 → 上級）

各難易度の問題はシャッフルした山から順に使い、使い切ったら並べ直します。直前と同じ問題は続けて出しません。
桜モードで「いろいろ」を選んだときも同じ順番の決まりを使います。難易度を選んだ練習と追加教材は、全体をシャッフルして出します。

## 記録を分ける条件

次がすべて同じ記録どうしだけで、前回比較と自己ベストを出します。

- 練習の種類（ローマ字／文章）
- 終わりかた（時間制の 3・5・10分／問題数制の 25・50問）
- 入力のしかた（実物のキーボード／画面）
- 問題の種類（標準・一般・桜モード・追加教材）、テーマ、難易度
- 問題セットの版（内蔵：`qs-2026.10`、追加教材：`teacher`）

自己ベストは完走した記録の中で「ランクが高い → 同じランクなら速い」ものです。
ランクが変わらなくても、速さ・正確率・正しい数・ミスの数が前回より良くなった点を結果画面で伝えます。

## 版の管理

- ランク基準：`src/core/rank.ts` の `RANK_VERSION` と、データベースの `private.rank_table`。基準を変えるときは新しい版を追加し、過去の結果は書き換えません（保存済みの結果には判定時の版とランクが残ります）。
- 問題セット：`src/core/questions.ts` の `QUESTION_SET_VERSION`。問題を追加・変更したら版を上げます。

検定モードの採点（得点文字数・ミス数・目安達成）は、上のタイピングの採点・ランクとは別の規則です。記録も別に保存し、ランクの計算には使いません。
