# 初期問題データ（問題セット qs-2026.10）

すべて、このアプリのために新しく作ったオリジナルの問題です。ほかのタイピングソフトやサービスの問題文・問題データ、検定の過去問題は収録していません。
構成（単語 → 小さい文字などを含む単語 → 短文 → 長文、テーマ別）は一般的なタイピング練習の形を参考にしました。
既存アプリ「漢字マスター」の問題データは使っていません（提供されていないため）。

## 件数

| 種類 | 区分 | 難易度1 | 難易度2 | 難易度3 | 合計 |
|---|---|---|---|---|---|
| ローマ字入力 | 一般 | 126 | 126 | 72 | **324** |
| ローマ字入力 | 🌸桜モード | 110 | 120 | 80 | **310** |
| 文章入力 | 一般 | 42 | 37 | 24 | **103** |
| 文章入力 | 🌸桜モード | 40 | 40 | 20 | **100** |

- ローマ字：難易度1＝やさしい単語（小さい文字・「ん」・長音なし）、2＝促音・拗音・「ん」・長音などを含む単語、3＝短文（「。」で終わる）
- 文章：難易度1＝初級（10〜30文字程度）、2＝中級（30〜80文字程度）、3＝上級（122〜184文字、一部に改行を含む）
- 文章入力の本文は合計約10,500文字あり、10分間の練習（S＋の速さでも約2,000文字）でも尽きません。問題はくり返しシャッフルして出すため、ローマ字入力も尽きません。

### テーマ

- 一般：身近な生活（life）、食べ物・動物・自然（food_nature）、趣味・音楽・スポーツ（hobby）、買い物・公共施設（shopping）、情報・パソコン（it）、短い説明文（explain）— 各テーマ ローマ字54問・文章17〜18問
- 🌸桜モード：学校生活（school）、通学・公共交通（commute）、実習・仕事（work）、学校行事（events）、友人関係・あいさつ（friends）、国語・敬語・お礼状（language）、進路・就職（career）、安全・防災（safety）、情報・ICT（ict）、お金・買い物・公共手続き（money）— 各テーマ ローマ字31問・文章10問

## データの形

`src/data/questions/*.json` に1問1行で入っています。

```json
{"id":"rg001","kind":"romaji","category":"general","theme":"life","difficulty":1,"text":"家族","reading":"かぞく"}
```

| 項目 | 内容 |
|---|---|
| id | `rg`（ローマ字・一般）`rs`（ローマ字・桜）`sg`（文章・一般）`ss`（文章・桜）＋3けたの番号 |
| kind | `romaji`（ローマ字入力）／`sentence`（文章入力） |
| category | `general`（一般）／`sakura`（桜モード） |
| theme | テーマ（上の一覧） |
| difficulty | 1〜3 |
| text | 画面に表示する本文。文章入力ではこれと同じ文を入力します。改行は `\n` |
| reading | 読み（ひらがな）。ローマ字入力ではこれを打ちます。文章入力では読みガイドに使います |

## 検証

| 確認すること | 方法 |
|---|---|
| ID・本文・読みの重複 | `npm run validate:questions`（`npm test` でも実行） |
| 語尾や固有名詞だけを変えたような、よく似た問題 | 同上（文字の2文字組の類似度 0.6 以上を検出） |
| 使えない文字（半角カナ・特殊な記号など） | 同上 |
| ローマ字で入力できない読み | 同上。さらに `npm test` で全問をガイドどおりに最後まで打てることを確認 |
| 本文と読みの句読点・かっこ・改行の並び | 同上 |
| 難易度と文字数・使っている文字の対応 | 同上 |
| 読み間違い | `npm run check:readings`：形態素解析の辞書で本文から読みを推定して比較。辞書の推定が違っていたもの（例：「七時」を辞書は「ななじ」、データは「しちじ」）は、確認して `scripts/reading-exceptions.json` に理由を書いています |

このほか、内容（高校生に合った自然な文か、不自然な日本語がないか）は作成時に目で確認しました。授業で使う前に、先生の目でも一度確認してください。

## 問題を追加・変更するとき

1. `src/data/questions/*.json` を編集します（ID は重ならないように続きの番号を付けます）。
2. `src/core/questions.ts` の `QUESTION_SET_VERSION` を新しい版にします（過去の記録と比較が混ざらないように）。
3. `npm run validate:questions` と `npm run check:readings` と `npm test` を実行し、すべて通ることを確かめます。

授業ごとの問題は、ここを変えずに、先生用の画面の「追加教材」で登録できます。
