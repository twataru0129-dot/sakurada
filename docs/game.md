# ゲームモード（v1.2.0）

ホームの「② ゲームモード」から、ゲームを選んで遊びます。この版で遊べるのは「サクラダファミリアを完成させよ」の1本です。
ゲームは `src/core/game/registry.ts` の一覧で管理しています（ゲームを追加するときは、ここに登録します。作成中のゲームは登録しません）。

## サクラダファミリアを完成させよ

何も建っていない敷地から始め、物語をローマ字で入力すると、少しずつ建築が進みます。物語を最後まで入力すると、必ず建物が完成します。
時間制限・ゲームオーバー・ミスによる建物の破壊はありません。速く正確に入力すると、記録タイムとゲーム内の完成年が良くなります。

- ゲーム名「サクラダファミリア」は桜打に掛けた名前です。物語の中の実在の建物名は「サグラダ・ファミリア」です。
- 建物の画像（6枚）は、ゲーム用に AI で作成したイラストです。実際の完成予想図や、過去の建築の様子・各年の街並みを正確に再現したものではありません。
- 完成年はゲーム内の換算です。実際のサグラダ・ファミリアの完成予定年とは関係ありません。

### ルール（版：sakurada-rule-v1）

- 正しく打つと工事が進む
- ミス1回で記録に5秒加算
- 最後まで打つと完成

```
ミス加算（ms）   = ミス回数 × 5000
記録タイム（ms） = 入力時間（ms）＋ ミス加算
完成年           = 1882 ＋ floor(記録タイム ÷ 2000)
```

計算は生のミリ秒で行い、表示だけを切り捨てて丸めます（例：記録3分46秒 → 1995年、4分56秒 → 2030年、8分 → 2122年。ミス6回・入力3分 → 記録3分30秒）。
上限は設けないため、遅くても負の完成年や失敗にはならず、違うタイムが同じ年に丸められることもありません。

入力時間は、スタートしてから最後の文を入力し終えるまでの実際の経過時間です（単調に増える時計で測ります）。タブを切り替えたり、画面のフォーカスが外れたりしても止まりません。
授業で中断するときは「一時停止」（または Esc キー）を使います。一時停止の間は時間も入力も止まり、一時停止の回数を記録します。一時停止した記録は、一時停止しなかった記録とは別に比べます。

### 入力と判定

- 1文ずつ、日本語の文・読み（ひらがな）・ローマ字のお手本（入力済み／未入力を区別。表示上の改行は「画面の配置」を参照）を表示します。文の最後を入力すると、待たずに次の文へ進みます。
- 判定は既存のローマ字判定（`RomajiMatcher`）をそのまま使います。shi / si、chi / ti、tsu / tu、ji / zi、nn / n、xtu などの別の打ち方も、すべて正解です。お手本の打鍵数を必須の打鍵数にはしていません。
- ミスは正解に進まず、ミス回数と加算時間（5秒）を増やします。強制的な待ち時間はなく、そのまま続けられます。ミスのときは「＋5秒」を小さく短く表示します。
- 日本語入力（IME）の変換中、Shift・Ctrl・Alt・Meta などの修飾キーやショートカット、Enter・Tab・矢印・ファンクションキー、スペース、キーの押しっぱなし（くり返し）は、ミスに数えません。終わったあとのキーでは数値は変わりません。
- 開始はスタートボタンかスペースキーです。ボタンなどを操作しているときのスペースは、その操作に使います。開始のキーはミスに数えません。
- 音、ローマ字のお手本（ヘボン式／訓令式）、ローマ字ガイド、キーボード・指のガイドの設定は、ほかのモードと共通です。入力のしかた（実物のキーボード／画面のキーをタップ）を選べます。

### 画面の配置（v1.3.1）

- PC・Surface（ブラウザの表示領域が幅1000px以上・高さ620px以上。ズーム100％の 1366×768・1280×720 を確認）では、横幅いっぱいを使い、縦にスクロールしなくても全体が見える配置にします。上から：
  1. モード名・コース・入力時間・ミス（加算時間）・ゲーム内の年・一時停止・やめる
  2. 工事の進み具合（ゲージ・完成率・完成まであと○文字・工程名）
  3. 左に建物の画像、右に入力する文。2つの枠は同じ幅・同じ高さで、上下の端がそろいます。画像は縦横比のまま枠に収めます（切り取り・引き伸ばしなし）。
  4. 大きなキーボード（全体を中央に）
  5. キーボードのすぐ下に「次のキー」「使う指」と手の図（中央に小さめに）
- 入力する文の枠：日本語の文の下に、読み（ひらがな）とローマ字を大きめ・左ぞろえで表示します。次に打つローマ字は色と下線で示します。
  - 改行は「、」「。」のあとで行い、長いときは枠の幅に合わせて言葉の切れ目（文と読みを対応づけて求めた、送りがな・助詞のあとに漢字・カタカナの言葉が始まる位置）で分けます。読みとローマ字は同じ位置で改行します。「きょ」「っか」などの入力の単位の途中では分けません（`src/core/game/romajiDisplay.ts`）。
  - 改行は表示だけです。Enter やスペースを打つ必要はなく、判定・ミス・残り文字数・完成率は変わりません。改行の位置はお手本の打ち方の長さで決めるため、si / shi など別の打ち方で入力しても、入力の途中で改行や枠の高さが変わりません（入力済みの部分は実際に打った文字を表示します）。
  - 長い文が枠に収まらないときは、文が変わったときに文字を少しずつ（最小 0.75 倍。日本語の文は 20px 以上）小さくして収めます。文字やキーを隠す指定はしていません。
- ゲーム用のキーボード（`src/ui/game/GameKeyboard.tsx`、`src/core/game/gameKeyboard.ts`）：この物語の入力に使う、英字26文字と「,」「.」「-」（ー）「/」（・）だけを表示します。キーを省いても左に詰めず、実物の日本語配列の位置関係と各段のずれ（Q→A→Z）を保ち、全体を中央に置きます。数字・Shift・Enter・Backspace・スペースは表示しないだけで、実物のキーボードの操作（Esc の一時停止など）は今までどおりです。指の色分け・次のキーの強調（キーボードガイド）・F と J の印があり、「画面のキーをタップ」のときはキーをタップして入力できます。必要なキーに過不足がないことは自動テストで確かめています（別の正しい打ち方のキーも含む）。
- タイピングモード・検定モードのキーボード（`src/ui/Keyboard.tsx`）は変更していません。
- それより狭い・低いとき（スマートフォン、拡大表示など）は、上から「進み具合・建物・入力する文・キーボード・指のガイド」の順に縦に並べ、情報を切り捨てずにスクロールで見られるようにします（横にはみ出しません）。スマートフォンでは「画面のキーをタップ」で遊べます。
- 工程が変わったときは、建物の画像の上に「塔の工事が始まった！」などを短く表示します（入力する文は覆いません。入力は止まりません）。

### ミスの効果音と表示（v1.3.0）

- ミス1回ごとに、短く低い効果音（全体の「音」の設定が ON のときだけ）、「＋5秒」の短い表示、入力枠の軽い強調を出します。専用の ON／OFF の設定はありません。
- 続けてミスしても、表示は1つだけで、音も重ならないよう間隔をあけます。ミスの判定と5秒の加算はゲームの処理で1回だけ行い、演出が加算を増やすことはありません。入力はそのまま続けられ、フォーカスも移りません。
- 動きを減らす設定（prefers-reduced-motion）のときは、動かさずに文字と枠だけで示します。

### ゴールまでの見通し（工事の進み具合）

常に見える位置に、次の4つを表示します。

1. 工事の進み具合のゲージ（role="progressbar"。読み上げは工程が変わったときだけ）
2. 完成率（例：65％）
3. 「完成まであと○文字」（読みの文字数）
4. いまの工程（準備／基礎工事／壁の建築／本体の建築／塔の建築／完成）

進み具合は、各文の読み（reading）の文字数（句読点を含む）で数えます。日本語の表示文の文字数や、実際の打鍵数とは別です。
ローマ字の入力単位（「きゃ」は2文字、「っか」も2文字）が確定したときに、そのかなの文字数を加えます。「ん」が次のキーと同時に確定する場合も、判定の進み方に合わせて数えます。
途中のローマ字だけを入力した段階では増えません。ミスでは増えず、戻らず、残りの文字数も変わりません。shi / si などの打ち方で総量や残りは変わりません。

| 完成率 | 工程・画像 |
|---|---|
| 0％ | 準備（更地） |
| 5％ | 基礎工事 |
| 20％ | 壁の建築（低い壁） |
| 40％ | 本体の建築 |
| 70％ | 塔の建築 |
| 100％ | 完成（全文を入力し終えたときだけ） |

工程は後戻りしません。画像6枚はすべて先に読み込み、同じ枠に `object-fit: contain`（上端・地面を切らない、引き伸ばさない）で重ねて、短いクロスフェードで切り替えます。読み込めないときは、再読み込みの案内と工程名・ゲージを表示します。
動きを減らす設定（prefers-reduced-motion）のときは、切り替え・光・花びらの動きを止めます。

画像は、提供された PNG（1536×1024）を同じ大きさのまま WebP に変換して同梱しています（`src/assets/game/`。切り取り・引き伸ばし・描き直しはしていません）。

### 完成記念画像（v1.3.0）

結果画面の「完成記念画像を保存」で、ゲーム名・完成した建物の画像・ゲーム内の完成年・記録タイム（ミス加算後）・正確率・コース・物語・（任意で）ニックネームを入れた PNG（1600×1600）を作れます。

- 画像は端末の中（canvas）で作ります。結果や名前を外部のサービスへ送ることはありません。完成の画像とフォントの準備ができてから作ります。
- 「ニックネームを載せる」を選んだときだけ名前を載せます（20文字まで。ログイン中は表示名を初めから入れます。ゲストに本名の入力は求めません）。
- PC では「PNGを保存する」でダウンロードします。iPhone・iPad では、共有に対応していれば「共有・写真に保存」で共有の画面を開きます（共有先は本人が選びます）。保存できないときは、表示された画像を長押しして「"写真"に保存」を選ぶよう案内します。
- ファイル名は `sakurada-memorial-年月日-時分秒.png`（日本語や名前を含みません）。画像の保存は成績の記録とは別の処理で、何度保存しても記録は増えません。保存に失敗しても、結果画面と記録はそのまま残ります。

### 結果と記録

結果画面には、完成画像・「西暦○○年、あなたのサクラダファミリアが完成！」・記録タイム（主な記録）と内訳（入力時間・ミス回数・ミス加算時間）・正確率・正しく打ったキーの数・物語・コースを表示します。
条件が同じ前回・自己ベストと比べ、「前回より○秒早く完成」「前回より○年早く完成」を伝えます（同じ年でも、秒の改善は伝えます）。初めてのときは「初めての完成！」と表示します。

- 比べる条件：ゲーム・ルールの版・物語の版・コース・物語・入力のしかた・一時停止の有無。物語ごとの自己ベストを主に比べ、同じコースの3本全体の自己ベストは参考として表示します。
- 記録は、タイピングの記録・ランク・成長グラフ、検定モードの記録とは混ぜません。
- 保存する項目：id（プレイ開始時に1回だけ作る UUID）、gameId、ruleVersion、storySetVersion、storyId、courseId、inputMethod、romajiStyle、startedAt、finishedAt、elapsedMs、missCount、penaltyMs、recordTimeMs、completionYear、correctKeystrokes、accuracy、completedReadingCharacters、totalReadingCharacters、pauseCount、finished。入力した文章・打鍵の記録は保存しません。
- 完成前に「やめる」を選んだプレイは記録しません（この版では途中終了の記録は残しません）。

**ゲスト**：この端末・ブラウザの localStorage に保存します。クラウドには送りません。
- 履歴：`sakura-type:guest-game-history:v1`（最新100件）
- 自己ベスト：`sakura-type:guest-game-bests:v1`（条件ごとの最も良い記録。履歴の100件から消えても残ります）
- 読み込むときに形式・数値・版を検証し、記録タイム・完成年などをルールで計算し直して一致しない値は読みません。保存できない・容量不足・破損のときは「記録しました」と表示しません。
- 「練習の記録 → ゲームの記録 → ゲストのゲームの記録と自己ベストをすべて削除」で、ゲームの履歴と自己ベストの両方を消します（タイピング・検定の記録は消しません）。

**ログイン利用者**：アカウント（Supabase の `game_results`）に保存します。
- ミス加算・記録タイム・完成年・正確率は、データベース側でルールに従って計算し直します。同じプレイ ID の二重の保存は起きません。
- 一覧は新しい順に100件、自己ベストは古い記録も含めて求めます（関数 `game_bests`）。
- 保存中／保存しました／保存できませんでした（通信の不具合・データベースに表がない）を分けて表示し、「もう一度保存する」で再送できます。保存できなかった記録は、ログアウトするまで画面と「ゲームの記録」に「未保存」として残ります（ログアウトしようとすると確認が出ます）。ゲストの保存場所に黙って切り替えることはしません。
- 先生は、担当する生徒の「くわしく・管理」でゲームの記録を見られます（二段階認証済みのとき）。

## Supabase を使う場合の設定

v1.3.0 では、新しい短縮版の物語を登録する `supabase/migrations/20261010000000_game_short_stories_v2.sql` を追加しました（`private.game_stories` に3行を追加するだけで、既存の行・記録は変更しません）。適用する前は、ログイン利用者の新しい短縮コースの記録だけが「クラウドに保存できていません」になります（標準コースの記録は保存できます）。


`supabase/migrations/20261009000000_game_results.sql` を、既存のマイグレーションのあとに適用します（[setup.md](setup.md) の手順2）。

- 表 `public.game_results`（RLS 有効）と、物語ごとの読みの文字数の表 `private.game_stories`、自己ベストの関数 `public.game_bests(uuid)`（security invoker：呼び出した人が見られる記録だけが対象）を作ります。
- 本人の追加（停止中のアカウントは不可）・本人の閲覧、担当の先生（二段階認証済み）の閲覧だけを許可します。変更・削除・未ログインでの読み書き・他人の ID での追加はできません。
- 適用する前は、ログイン利用者のゲームの記録は「クラウドに保存できていません（データベースにゲームの記録の表がまだありません）」と表示されます。
