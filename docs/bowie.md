# ボウイの爆弾遊戯（v1.5.0）

ボウイが投げる爆弾を、表示された文字をローマ字で入力して解除するゲームです。ゲームモードの「ゲームの選択」から入ります（`#/game/bowie`）。

## 遊び方

1. 「ゲームの選択」で「ボウイの爆弾遊戯」を選ぶと、タイトルコールが流れ、画面全体が白 → 黒 → ゲーム画面の順に切り替わります（下の「タイトルコール」）。ゲーム画面（開始前の画面）が出たら、スタートのボタン（またはスペース）で始まります。
2. ボウイが爆弾を投げ、**爆弾が手を離れた瞬間に**問題（日本語・かな・ローマ字のお手本）が出ます。投球中・段階の表示中・カットイン中に打ったキーは捨てます（次の問題にためません）。
3. 最後の文字まで入力すると解除。早く解除するほど高得点です。ミスは減点なし（赤い表示・揺れ・ミスの音だけで、入力は進みません）。
4. 爆弾が主人公に届くと、その場で終了（爆発と主人公の被弾の声 → DEFEAT の画像と敗北の音声 → ゲームオーバーの煽り画像と笑い声 → 主人公の鳴き声。実際の得点・再挑戦・ホーム）。
5. 4段階 × 20問 ＝ 全80問を解除すると勝利（クリアの曲に合わせて主人公のダンス → 勝利の音 → ボウイの絶望の画像とセリフ）。演出は「演出を飛ばす」で飛ばせます。

- 入力は小文字のままで構いません（Shift つきの大文字も受け付けます）。表示は大文字。入力済み・次の文字・残りを色で区別します。
- 判定は桜打の共通のローマ字判定（`src/core/romaji.ts`）で、別の打ち方（si / shi、tu / tsu など）も正解。「ー」は `-`、句読点・表示用の空白は入力不要。文章は `display_segments` のまとまりで改行して表示します。
- このモードだけの決まり（`BOWIE_ROMAJI_RULES`。ほかのモードの判定は変わりません）：
  - 「ん」はすべて **NN** で入力します。語末・子音・母音・や行・な行の前も同じです（例：かん → KANN、かんい → KANNI、しんよう → SHINNYOU、きんにく → KINNNIKU、かんな → KANNNA）。1回目の N は入力の途中で、2回目の N で「ん」が確定します。N 1回・N'・XN では確定せず、爆弾も解除されません。お手本の表示も NN です。
  - 「づ」は **DU・ZU** のどちらも正解です（お手本は DU。ZU で打つと表示も ZU に変わって進みます）。「ず」は ZU だけで、DU は正解になりません。
- 日本語入力（IME）がオンのとき、変換中の入力は判定に使わず、案内を出します（OS の IME をプログラムで切り替えることはしません）。
- 一時停止：右上のボタンか Esc。再開は 3・2・1 のカウントのあと。タブを切り替えた・ウィンドウから離れたときは自動で一時停止します。一時停止の間はゲームの時間・爆弾・音が止まります。
- 音：タイトルとプレイ中の「音：ON／OFF」ですぐに切り替え（桜打の共通の「音」の設定。保存済みの OFF はそのままです）。
- サウンド設定（v1.6.0）：タイトルの「サウンド設定」と、プレイ中の一時停止の画面から開きます（設定の間はゲームが止まり、入力の判定もしません）。
  - サウンド：オフ／オン、音楽・効果音・ボイス：それぞれ 0〜100％。初期値はオン・音楽 20％・効果音 80％・ボイス 100％。
  - 「デフォルトに戻す」：このゲームのサウンド設定だけを初期値に戻します（ほかの学習設定は変えません）。
  - 音量はこの端末（localStorage `sakura-type:bowie-sound:v1`）に保存し、次回も使います。v1.5.x の「全体の音量」を保存していた場合は、初めて開くときにその割合を引き継ぎます。
  - 分類：音楽＝通常の BGM・クリアの曲／効果音＝投球・解除・ミス・警告・爆発・カットインの登場音と地鳴り／ボイス＝タイトルコール・ボウイのセリフと笑い声・主人公の声・VICTORY／DEFEAT の音声。
  - 各音の音量（`src/ui/bowie/audio.ts` の `SOUNDS`・`RETUNE`）は、同じ種類の中で平均の大きさがそろうように調整しています（大きく録音されていた VICTORY・DEFEAT は下げました）。最後にリミッターを通し、音量を上げても割れないようにしています。
- 通常の BGM（v1.6.0）：ゲームの選択からのタイトルコールと白・黒の幕が終わり、ゲーム画面が出てから流し始め、開始待ちからプレイ中までくり返します（段階・カットインで最初から流し直しません）。
  - カットインのセリフの間は小さく（35％）し、終わると戻します。一時停止の間は止まり、再開すると続きから。被弾・全問クリア・ホームへ移るときに止め、再挑戦では最初から1回だけ流します。
  - くり返しのつなぎ目：2回目からは曲の先頭の無音（約0.04秒）を飛ばし、曲の終わりの0.015秒を消して、プツッという音が出ないようにしています。

## 出題

- 問題は `src/data/bowie/questions.json`（納品された問題をそのまま収録。文・読み・確認メモは変更していません）。段階1〜3は単語（111・106・113問）、段階4は文章（110問）。
- 各段階で重複なし・ランダムな順に20問を選びます（`src/core/bowie/questions.ts`）。確認メモは内部データで、画面には出しません。

## 得点と時間

- 爆弾の進み具合 p ＝ 手を離れてからの時間 ÷ 着弾時間（0〜1、等速）。得点 ＝ max(1, ceil(M × (1 − p)))、M は単語10点・文章20点。p ≥ 1 は被弾（同じ時刻の解除と衝突は衝突を優先）。最高 60×10 ＋ 20×20 ＝ 1000点。
- 着弾時間（秒）：段階1 5 / 4.5、段階2 6 / 5.5、段階3 7 / 6.5、段階4 15 / 14（各段階の1〜10問目 / 11〜20問目）。
- 残りの距離が20％になると危険エリア（1回だけ警告音・主人公が汗・画面の端が赤く）。
- 各段階の10問目を解除した直後（通算10・30・50・70問目のあと）に加速のカットイン。合計4回で、回ごとに決まった画像とセリフです（ランダムではありません。`BOWIE_CUTINS`）。
  | 回 | 画像 | セリフ（音声） | 長さ |
  |---|---|---|---|
  | 1 | `speed_cutin`（「少しテンポを落とそうか」の文字入り） | `bowie_level_up.mp3` | 約2.2秒（従来どおり） |
  | 2 | `bowie_cutin_02_text`（眼鏡に手を添えて笑う・「次の戦いの準備をしよう」の文字入り。v1.6.1） | `bowie_cutin_02_voice.mp3`（2.43秒） | 約3.1秒 |
  | 3 | `bowie_cutin_03_text`（手で顔の半分を隠す・「さて、私が流れを変えてみせよう」の文字入り。v1.6.1） | `bowie_cutin_03_voice.mp3`（3.37秒） | 約4.0秒 |
  | 4 | `bowie_cutin_04_text`（両手を広げて叫ぶ・「払いのける！」の文字入り。v1.6.1） | `bowie_cutin_04_voice.mp3`（1.78秒） | 約2.4秒 |
  - 画面全体の帯が右から入り（0.25秒）、入りきったところでその回のセリフを1回だけ流し、セリフが最後まで終わって0.16秒の余韻のあとに左へ抜けます（0.25秒）。長さはセリフの長さで決まり、読み込んだ音が登録より長ければそちらに合わせます（途中で切りません）。
  - 入り始めに「シャキーン」（cutin_shine）と地鳴り（cutin_rumble）。セリフの間は地鳴りを小さく（0.18）して、セリフを聞き取りやすくしています。2〜4回目のセリフの音量は、1回目と平均の大きさがそろうように 0.75〜0.8 にしています。
  - 画像は縦横比を保ったまま全体を見せ（キャラクターを切らない）、画面との縦横比の差の部分には同じ画像をぼかして敷きます。2〜4回目の画像には文字がなく、セリフの文字も重ねません。
  - カットインの間はゲームの時間が止まり、爆弾の移動・着弾・投球・入力の判定も止まります（再開しても爆弾が急に進みません）。音を OFF にしたとき・音を読み込めないときも、セリフの長さだけ表示して進みます。
- 時間はフレーム数ではなく1つの時計（一時停止の時間を除いた実時間）で決めます。

## 記録

- ハイスコアはプロフィールごと（ゲスト／ログイン利用者の内部 ID）に、この端末の localStorage `sakura-type:bowie-records:v1` に保存します。新しいデータベースの設定は不要です（クラウドには送りません。別の端末とは同期しません）。

## タイトルコール（ゲームの選択から入るとき）

選択 → タイトルコール（`bowie_title_call.mp3`）の再生と同時に白へ（約0.35秒）→ 音声が終わるまで白 → 音声の終わり（再生の ended）に合わせて白から黒へ（約0.35秒）→ 黒のまま（約0.15秒）→ ゲーム画面へ（約0.4秒）。

- 幕はヘッダーを含めた表示画面の全体を覆います。白くなってからゲーム画面に切り替え、その画像を読み込んでから黒へ移るため、選択画面や読み込み前の画像は見えません。
- 幕が消えるまで、投球・制限時間・入力の判定は始まりません。幕が消えたあとは開始待ちです。幕の間のキーはどの画面にも渡しません（ゲームの開始・最初の問題へ持ち越しません）。
- クリック・タップ・キー（Enter・スペース）での決定で同じ演出です。ポインターを重ねる・フォーカスを移すだけでは鳴りません。連打しても演出・遷移は1回です。
- 音は「音」の設定（ミュート）とこのゲームの音量に従います。ミュート・読み込みの失敗・再生の拒否のときは、音声の長さ（3.864秒）で進めます。音声が終わらないまま止まったときも、長さ＋2.5秒で先へ進めます。
- 途中で別の画面へ移ったとき（ブラウザの「戻る」など）は、音・タイマー・幕をすべて止めて消します。選択画面から選び直すと、もう一度1回だけ演出します。
- 時間の設定は `src/core/bowie/config.ts` の `BOWIE_TITLE_CALL`、処理は `src/ui/bowie/TitleCall.tsx` です。URL で直接ゲーム画面を開いたとき（再読み込みなど）は演出しません。

## 調整できる設定

- `src/ui/bowie/audio.ts`：各音の音量・種類、BGM のつなぎ目。`src/data/bowieSound.ts`：サウンド設定の初期値。`src/screens/bowie/BowieScreen.tsx` の `BGM_DUCK`（カットインのセリフの間の BGM）・`DANCE_BEAT_MS`（ダンスの拍）。
- `src/core/bowie/config.ts`：段階アップの文字・ボイス・長さ（`BOWIE_LEVEL_UPS`・`BOWIE_CONFIG.levelUp`）、このモードのローマ字の決まり（`BOWIE_ROMAJI_RULES`）、タイトルコールの幕の時間（`BOWIE_TITLE_CALL`）、出題数、着弾時間、得点の上限、投球の動作の長さ・各画像の比、危険エリアの割合、段階の表示・カットインの長さ、再開のカウント、ミスの音の間隔、解除の演出の時間。
- `src/ui/bowie/geometry.ts`：キャラクターの大きさ・位置、地面の高さ、衝突ライン、爆弾の弧。
- `src/ui/bowie/audio.ts`：効果音とボイスの経路の音量（各音の音量は `assets/bowie-source/asset_manifest.json`）。

## 素材

- ゲームオーバーの煽り画像は `game_over_01`〜`game_over_10` の10枚です。敗北ごとに均等な確率で1枚を選び、結果画面の表示中は変えません。再挑戦時は改めて抽選します（同じ画像が続く場合もあります）。
- 被弾：通常の BGM を止め、爆発の音と主人公の被弾の声（`bowie_hero_hit_voice.mp3`）を同時に流し、両方が終わるまで主人公の被弾のリアクションを見せます。そのあと DEFEAT の画像（`bowie_defeat`）と敗北の音声（`bowie_defeat.mp3`）→ 選ばれた煽り画像と笑い声（`bowie_laugh.mp3`）→ 笑い声が終わったら主人公の鳴き声（`bowie_hero_cry.mp3`）の順に出します（鳴き声は結果の画面のまま。終わるのを待たずに再挑戦・ホームへ移れ、そのときは音をすべて止めます）。DEFEAT の画像は画面全体に縦横比を保って収め（中央の文字と紋章を切りません）、セリフ・点数・操作の案内は重ねず、敗北の音声が終わると自動で煽りの画面へ移ります（音を OFF にしたときも音声の長さだけ表示します）。「演出を飛ばす」のボタンだけは、画像に重ならない下の帯に置いています。「演出を飛ばす」でも選んだ画像を表示し、笑い声 → 鳴き声を各1回再生します。共通の音量・ミュートに従い、再挑戦・ホームへ戻ると再生中の音を止めます。
- 10枚のセリフと対応は `src/ui/bowie/taunts.ts`。画像の元ファイルは `assets/bowie-source/images/scenes/game_over_01.png`〜`game_over_10.png`、配信用は `src/assets/bowie/scenes/` の同名 WebP です。旧画像 `game_over_clean` は履歴用に残していますが、結果画面では使いません。

- 納品された素材の元ファイル（画像・音声・manifest・設定）は `assets/bowie-source/`（配信しません）。
- `python3 scripts/bowie_assets.py` で、キャラクターの画像を余白で切り出し、足元・体の高さ・爆弾の位置を `src/data/bowie/sprites.json` に記録し、WebP に変換して `src/assets/bowie/` に出力します。音声（MP3）はそのまま複製します。

## 開発用の短縮（通常の画面には出ません）

E2E テスト用に、sessionStorage `sakura-type:bowie-dev` に `{"perStage":2,"timeScale":0.2}` のように入れると、出題数・時間を短くできます（`"ids":["word_1_016", …]` で各段階の最初の問題も指定できます）（ゲストで入ったあとに設定します。ゲストの開始・ログアウトで消えます）。

## 既知の点

- 問題データの表示用ローマ字の例（`romaji`）は、子音の前の「ん」を N 1つで書いているものがあります。このモードの判定は NN だけのため、画面のお手本は NN で表示します（問題の文・読み・段階・出題数は変えていません）。
- sentence_030・056・057 の表示例は「づ」が ZU です。このモードでは ZU も正解で、お手本は DU です。

画面の画像は `docs/screenshots/v1.5.0/`（開発用の短縮〔各段階2問〕で撮影しています）。

## 解除の音・クリアのダンス（v1.6.0）

- 解除の音は `bowie_disarm_v2.mp3`（約1.2秒）。解除1回につき1回だけで、次の投球は音の終わりを待たずにすぐ始まります（旧解除音は使いません）。
- 全問クリア：通常の BGM を止め、クリアの曲（`bowie_hero_clear_bgm.mp3`、約5.9秒、くり返しなし）を流している間、ステージの背景の中央で主人公が踊ります。
  - 「両手を上げた姿」「両手を下げた姿」（`hero_dance_up`／`hero_dance_down`）を半拍（0.2秒）ずつ切り替え、1拍（0.4秒・曲は約150 BPM）ごとに小さく跳ね、2拍で左右に揺れます。2枚は同じ範囲・同じ大きさで切り出してあるため、切り替えで体がずれません。元の画像の体から離れたほぼ透明な点は、背景に枠が出ないように消しています（`scripts/bowie_assets.py` の `dance()`）。
  - 曲が終わるとダンスを終え、VICTORY の音声 → ボウイの絶望のセリフ（これまでどおり）。「演出を飛ばす」で、曲とダンスを止めてクリアの表示へ進みます。
  - 「視差効果を減らす」の設定では、跳ねる・揺れる動きを止め、両手の切り替えだけにします。
- 音を OFF・音量0・読み込みの失敗のときも、被弾のリアクションとダンスは音の長さだけ表示して進みます。

## 段階アップ（v1.6.1）

通算20・40・60問を解除して第2〜4段階に入るとき、ステージの中央に横長の黒い帯が走り、赤と金の光とともに文字が出ます（文字は一瞬大きくなって収まり、短い金属音）。帯は半透明で、後ろのゲーム画面は見えたままです。下の欄は「ボウイがレベルアップしました」だけを出します（段階の長さの説明は出しません）。

| 解除した数 | 大きな文字 | 小さな文字 | ボウイのボイス（1回） |
|---|---|---|---|
| 20問 | ボウイ覚醒 | LEVEL 02 | `bowie_voice_212302.mp3`（3.50秒）「賢いものは私の邪魔をしませんよ」 |
| 40問 | 力の解放 | LEVEL 03 | `bowie_voice_212407.mp3`（3.76秒）「それで？反撃すらできないのですか？」 |
| 60問 | 終焉の遊戯 | FINAL LEVEL | `bowie_voice_212220.mp3`（1.54秒）「勝負を決めますよ！」 |

- 文字が出て 0.45 秒後にボイスを流し、ボイスが最後まで終わって 0.3 秒後に次の問題の投球を始めます（読み込んだ音の長さが登録より長ければ、そちらに合わせます）。ボイスのセリフは字幕にしません。
- 演出の間は、投球・爆弾の移動・着弾の計時・入力の判定が進みません。演出の間に打ったキーは捨て、次の問題へ持ち越しません。
- ボイスはボイスの音量、金属音は効果音の音量に従います。金属音は素材の音声がないため、少しずれた高さの音を重ねて作っています（`src/ui/bowie/audio.ts` の `metal()`）。
- 通常の BGM は流し直さず、ボイスの間は小さくして（カットインと同じ 35％）、終わると戻します。
- 音を OFF・音量0・ボイスの読み込みや再生の失敗でも、登録したボイスの長さだけ表示して進みます。一時停止・「やめる」・再挑戦・ホームでは、ボイス・演出を止めます（「やめる」で開始前の画面に戻ると、BGM は大きさを戻して流れます）。
- 第1段階の始まりは、これまでどおりの表示です（段階アップの表示・ボイスは使いません）。
- 20・40・60問の段階アップと、10・30・50・70問のあとのカットインは別の演出です。

## 開始前の画面（v1.6.1）

- 背景は星空と城の舞台の画像（`bowie_title_background`）。画面いっぱいに、引き伸ばさずに配置します（プレイ中の背景は従来の `stage_background` のまま）。
- 中央の上にタイトルロゴ、その下に大きなスタートのボタン。ハイスコア・音の ON／OFF・サウンド設定・遊び方・ゲームの選択にもどるは、薄い暗色の面にまとめて控えめに置きます。
- 遊び方の説明は、初めは出しません。「遊び方」のボタンで、説明の全文をダイアログで見られます（閉じるボタン・Esc で閉じ、閉じると「遊び方」のボタンへ戻ります）。ダイアログやサウンド設定を開いている間は、スペースでゲームが始まりません。
- タイトルコール → 白 → 黒 → 開始前の画面、画面が出てからの BGM、スペース・ボタンでの開始はこれまでどおりです。
