# ボウイの爆弾遊戯（v1.5.0）

ボウイが投げる爆弾を、表示された文字をローマ字で入力して解除するゲームです。ゲームモードの「ゲームの選択」から入ります（`#/game/bowie`）。

## 遊び方

1. 「ゲームの選択」で「ボウイの爆弾遊戯」を選ぶと、タイトルコールが流れ、画面全体が白 → 黒 → ゲーム画面の順に切り替わります（下の「タイトルコール」）。ゲーム画面が出たら、開始ボタン（またはスペース）で始まります。
2. ボウイが爆弾を投げ、**爆弾が手を離れた瞬間に**問題（日本語・かな・ローマ字のお手本）が出ます。投球中・段階の表示中・カットイン中に打ったキーは捨てます（次の問題にためません）。
3. 最後の文字まで入力すると解除。早く解除するほど高得点です。ミスは減点なし（赤い表示・揺れ・ミスの音だけで、入力は進みません）。
4. 爆弾が主人公に届くと、その場で終了（爆発 → 敗北の音 → ゲームオーバーの画像と笑い声。実際の得点・再挑戦・ホーム）。
5. 4段階 × 20問 ＝ 全80問を解除すると勝利（勝利の音 → ボウイの絶望の画像とセリフ）。演出は「演出を飛ばす」で飛ばせます。

- 入力は小文字のままで構いません（Shift つきの大文字も受け付けます）。表示は大文字。入力済み・次の文字・残りを色で区別します。
- 判定は桜打の共通のローマ字判定（`src/core/romaji.ts`）で、別の打ち方（si / shi、tu / tsu など）も正解。「ー」は `-`、句読点・表示用の空白は入力不要。文章は `display_segments` のまとまりで改行して表示します。
- このモードだけの決まり（`BOWIE_ROMAJI_RULES`。ほかのモードの判定は変わりません）：
  - 「ん」はすべて **NN** で入力します。語末・子音・母音・や行・な行の前も同じです（例：かん → KANN、かんい → KANNI、しんよう → SHINNYOU、きんにく → KINNNIKU、かんな → KANNNA）。1回目の N は入力の途中で、2回目の N で「ん」が確定します。N 1回・N'・XN では確定せず、爆弾も解除されません。お手本の表示も NN です。
  - 「づ」は **DU・ZU** のどちらも正解です（お手本は DU。ZU で打つと表示も ZU に変わって進みます）。「ず」は ZU だけで、DU は正解になりません。
- 日本語入力（IME）がオンのとき、変換中の入力は判定に使わず、案内を出します（OS の IME をプログラムで切り替えることはしません）。
- 一時停止：右上のボタンか Esc。再開は 3・2・1 のカウントのあと。タブを切り替えた・ウィンドウから離れたときは自動で一時停止します。一時停止の間はゲームの時間・爆弾・音が止まります。
- 音量・ミュート：タイトルとプレイ中の音のボタン。ミュートは桜打の共通の「音」の設定、音量はこの端末（localStorage `sakura-type:bowie-volume:v1`）に保存します。

## 出題

- 問題は `src/data/bowie/questions.json`（納品された問題をそのまま収録。文・読み・確認メモは変更していません）。段階1〜3は単語（111・106・113問）、段階4は文章（110問）。
- 各段階で重複なし・ランダムな順に20問を選びます（`src/core/bowie/questions.ts`）。確認メモは内部データで、画面には出しません。

## 得点と時間

- 爆弾の進み具合 p ＝ 手を離れてからの時間 ÷ 着弾時間（0〜1、等速）。得点 ＝ max(1, ceil(M × (1 − p)))、M は単語10点・文章20点。p ≥ 1 は被弾（同じ時刻の解除と衝突は衝突を優先）。最高 60×10 ＋ 20×20 ＝ 1000点。
- 着弾時間（秒）：段階1 5 / 4.5、段階2 6 / 5.5、段階3 7 / 6.5、段階4 15 / 14（各段階の1〜10問目 / 11〜20問目）。
- 残りの距離が20％になると危険エリア（1回だけ警告音・主人公が汗・画面の端が赤く）。
- 各段階の10問目を解除した直後に加速のカットイン（全面・右から左、約2.2秒。光の音＋地鳴り〔セリフの間は音量0.18〕＋セリフ）。合計4回。カットインの間はゲームの時間が止まります。
- 時間はフレーム数ではなく1つの時計（一時停止の時間を除いた実時間）で決めます。

## 記録

- ハイスコアはプロフィールごと（ゲスト／ログイン利用者の内部 ID）に、この端末の localStorage `sakura-type:bowie-records:v1` に保存します。新しいデータベースの設定は不要です（クラウドには送りません。別の端末とは同期しません）。

## タイトルコール（ゲームの選択から入るとき）

選択 → タイトルコール（`bowie_title_call.mp3`）の再生と同時に白へ（約0.35秒）→ 音声が終わるまで白 → 音声の終わり（再生の ended）に合わせて白から黒へ（約0.35秒）→ 黒のまま（約0.15秒）→ ゲーム画面へ（約0.4秒）。

- 幕はヘッダーを含めた表示画面の全体を覆います。白くなってからゲーム画面に切り替え、その画像を読み込んでから黒へ移るため、選択画面や読み込み前の画像は見えません。
- 幕が消えるまで、投球・制限時間・入力の判定は始まりません。幕が消えたあとは開始待ちです。幕の間のキーはどの画面にも渡しません（ゲームの開始・最初の問題へ持ち越しません）。
- クリック・タップ・キー（Enter・スペース）での決定で同じ演出です。ポインターを重ねる・フォーカスを移すだけでは鳴りません。連打しても演出・遷移は1回です。
- 音は「音」の設定（ミュート）とこのゲームの音量に従います。ミュート・読み込みの失敗・再生の拒否のときは、音声の長さ（3.864秒）で進めます。音声が終わらないまま止まったときも、長さ＋2.5秒で先へ進めます。
- 途中で別の画面へ移ったとき（ブラウザの「戻る」など）は、音・タイマー・幕をすべて止めて消します。選択画面から選び直すと、もう一度1回だけ演出します。
- 時間の設定は `src/core/bowie/config.ts` の `BOWIE_TITLE_CALL`、処理は `src/ui/bowie/TitleCall.tsx` です。URL で直接ゲーム画面を開いたとき（再読み込みなど）は演出しません。

## 調整できる設定

- `src/core/bowie/config.ts`：このモードのローマ字の決まり（`BOWIE_ROMAJI_RULES`）、タイトルコールの幕の時間（`BOWIE_TITLE_CALL`）、出題数、着弾時間、得点の上限、投球の動作の長さ・各画像の比、危険エリアの割合、段階の表示・カットインの長さ、再開のカウント、ミスの音の間隔、解除の演出の時間。
- `src/ui/bowie/geometry.ts`：キャラクターの大きさ・位置、地面の高さ、衝突ライン、爆弾の弧。
- `src/ui/bowie/audio.ts`：効果音とボイスの経路の音量（各音の音量は `assets/bowie-source/asset_manifest.json`）。

## 素材

- ゲームオーバーの煽り画像は `game_over_01`〜`game_over_10` の10枚です。敗北ごとに均等な確率で1枚を選び、結果画面の表示中は変えません。再挑戦時は改めて抽選します（同じ画像が続く場合もあります）。
- 爆発 → 敗北の音 → 選ばれた煽り画像と笑い声（`bowie_laugh.mp3`）の順に出します。「演出を飛ばす」でも選んだ画像を表示し、笑い声を1回再生します。共通の音量・ミュートに従い、再挑戦・ホームへ戻ると再生中の音を止めます。
- 10枚のセリフと対応は `src/ui/bowie/taunts.ts`。画像の元ファイルは `assets/bowie-source/images/scenes/game_over_01.png`〜`game_over_10.png`、配信用は `src/assets/bowie/scenes/` の同名 WebP です。旧画像 `game_over_clean` は履歴用に残していますが、結果画面では使いません。

- 納品された素材の元ファイル（画像・音声・manifest・設定）は `assets/bowie-source/`（配信しません）。
- `python3 scripts/bowie_assets.py` で、キャラクターの画像を余白で切り出し、足元・体の高さ・爆弾の位置を `src/data/bowie/sprites.json` に記録し、WebP に変換して `src/assets/bowie/` に出力します。音声（MP3）はそのまま複製します。

## 開発用の短縮（通常の画面には出ません）

E2E テスト用に、sessionStorage `sakura-type:bowie-dev` に `{"perStage":2,"timeScale":0.2}` のように入れると、出題数・時間を短くできます（`"ids":["word_1_016", …]` で各段階の最初の問題も指定できます）（ゲストで入ったあとに設定します。ゲストの開始・ログアウトで消えます）。

## 既知の点

- 問題データの表示用ローマ字の例（`romaji`）は、子音の前の「ん」を N 1つで書いているものがあります。このモードの判定は NN だけのため、画面のお手本は NN で表示します（問題の文・読み・段階・出題数は変えていません）。
- sentence_030・056・057 の表示例は「づ」が ZU です。このモードでは ZU も正解で、お手本は DU です。

画面の画像は `docs/screenshots/v1.5.0/`（開発用の短縮〔各段階2問〕で撮影しています）。
